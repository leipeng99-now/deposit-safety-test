# CloudBase 后端部署说明（方案 B）

> 环境 ID：`leipeng99-d8gq6j5dzb0a65db1`
> 目标：密码校验与次数统计放云端，**全设备统一计数**，换手机/换电脑都无法重复使用同一密码。

---

## 一、部署云函数（二选一）

### 方式 A：控制台手动部署（约 3 分钟）

1. 打开 [CloudBase 控制台](https://console.cloud.tencent.com/tcb) → 选中环境 `leipeng99-d8gq6j5dzb0a65db1`
2. 左侧 **云函数** → **新建云函数**
   - 函数名称：`pwd`（必须叫这个）
   - 运行环境：**Nodejs18.15**
   - 创建方式：**在线编辑**
3. 把本目录 `functions/pwd/index.js` 的全部内容，覆盖粘贴进编辑器里的 `index.js`
4. 在 `package.json` 页签里，粘贴本目录 `functions/pwd/package.json` 的内容
5. 点 **保存**（会自动安装 `@cloudbase/node-sdk` 依赖，等几十秒）

### 方式 B：命令行部署

```bash
npm i -g @cloudbase/cli
tcb login
tcb fn deploy pwd --dir ./cloudbase/functions/pwd -e leipeng99-d8gq6j5dzb0a65db1
```

## 二、开启 HTTP 访问服务（关键，前端就靠这个地址访问）

1. 控制台 → 左侧 **HTTP 访问服务**（部分版本在「环境 → HTTP 访问服务」）
2. 点 **新建** / **添加路径**
   - 路径：`/pwd`
   - 指向函数：`pwd`
3. 保存后会得到一条访问地址，形如：

```
https://leipeng99-d8gq6j5dzb0a65db1-1234567890.ap-shanghai.app.tcloudbase.com/pwd
```

> 这条地址就是 `config.js` 里要填的 `CLOUDBASE_API_BASE`。

## 三、验证部署是否成功

浏览器直接打开（GET 也能测）：

```
https://你的访问地址/pwd?action=check&code=CKAQ-2601
```

- 成功返回：`{"ok":true,"valid":true,"remain":3}`
- 密码不存在：`{"ok":true,"valid":false,"reason":"wrong","remain":0}`

首次调用时会**自动建表并播种 50 个密码**（`test_passwords` / `test_usage` 两个集合），无需手动导入数据。

## 四、前端接入

拿到地址后填进 `deposit-test-site/config.js`：

```js
const CLOUDBASE_API_BASE = "https://xxxxx.app.tcloudbase.com/pwd";
```

填好后推送 GitHub，即生效。此时：
- 密码校验走 CloudBase（国内直连，秒开）
- 每个密码**全局共 3 次**，用完即失效（跨设备统一）
- 前端可以清空 `PASSWORDS` 明文列表（更好：别人看不到你的密码池）

## 五、日常运营

### 卖新密码 / 加密码

控制台 → 数据库 → 集合 `test_passwords` → 添加记录：

```json
{ "code": "CKAQ-2651", "active": true, "used": 0, "max": 3 }
```

### 作废某个密码（比如退款/外泄）

把该记录的 `active` 改成 `false`，即时生效，前端无需重新发布。

### 改某个密码的可测次数

改 `max` 字段即可（如 VIP 码设 `max: 10`）。

### 看谁在用、用了多少次

集合 `test_usage` 里是流水记录：`{ code, device, at }`，可按 `code` 统计。

## 六、接口说明（前端已对接，无需改动）

| action | 请求 | 返回 |
|---|---|---|
| `check` | `{action:"check", code:"CKAQ-2601"}` | `{ok:true, valid:true, remain:2}` / `{ok:true, valid:false, reason:"wrong"}` |
| `remain` | `{action:"remain", code:"CKAQ-2601"}` | `{ok:true, remain:2}` |
| `consume` | `{action:"consume", code:"CKAQ-2601", device:"xxx"}` | `{ok:true, valid:true, used:1, remain:1}` |

前端用 `text/plain` 发送 JSON，绕过跨域预检（OPTIONS），保证在 GitHub Pages 上稳定可用。
